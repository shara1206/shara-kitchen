🔴 麻辣红汤锅（川渝火锅）

锅底味重，蘸料要清爽解辣。

  • 经典油碟：香油碗底 + 蒜泥。从辣锅里捞出来的肉裹上芝麻香油，回味无穷。
  • 可外挂：蚝油、葱花、香菜、辣椒面
→ 查看配方

⬜ 清汤 / 菌菇 / 番茄锅

锅底清淡，蘸料可以更有层次感。

  • 酸辣口：香菜 + 葱花 + 小米辣 + 生抽 + 醋
  • 麻酱系：蒜泥 + 麻酱 + 白糖 + 蚝油 + 生抽 + 醋

🐑 老北京涮羊肉（清水铜锅）

最经典的北派搭配，腐乳和麻酱能压住羊肉的膻味。

  • 芝麻酱 — 用温水调至可流动的稠度
  • 韭菜花酱
  • 腐乳汁（红腐乳）
  • 辣椒油、葱花、香菜

🥩 潮汕牛肉火锅（清汤）

锅底极清，为了吃出牛肉原味，不适合重口蘸料，否则盖住牛肉香。

  • 沙茶酱 — 打底
  • 生抽
  • 蛋黄（可选，增加浓郁感）

🦐 海鲜火锅

咸香辣混合，特别适合蘸鱼虾贝类。

  • 芝麻酱
  • 腐乳汁
  • 辣椒油
  • 香菜 + 芝麻粒

🍖 干碟（重庆特色）

不用液体蘸料，把肉按进粉碟里。特别适合嫩牛肉，有点像烤肉的感觉。

  • 花生碎
  • 白芝麻
  • 辣椒粉
  • 盐

核心逻辑

→ 锅底越辣 → 蘸料越清淡（油碟解辣）
→ 锅底越清 → 蘸料越丰富（补充味道）
→ 羊肉 / 牛肉 → 麻酱 / 腐乳系（去膻）
→ 海鲜 → 麻酱 / 沙茶酱（提鲜）
